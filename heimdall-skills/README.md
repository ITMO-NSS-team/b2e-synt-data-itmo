# Скиллы канала v2

Каталог скиллов эмулятора. Здесь лежат рецепты (`.yaml`) и приёмы (`.md`),
которые B2E-агент получает через `find_skills` / `get_skill`.

Пустой каталог допустим: витрины отвечают и без скиллов, но агент тогда
вынужден собирать тело `mcp_query` сам — это один из режимов эксперимента.
