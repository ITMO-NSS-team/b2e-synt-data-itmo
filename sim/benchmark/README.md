# Бенчмарк

Конфигурация эксперимента хранится в `sim/benchmark/.env`, шаблон — `.env.example`.
Локальный `.env` исключён из Git и Docker-контекста. Python-модули находятся в
`sim/benchmark`; этот перенос меняет конфигурацию, а не структуру кода.

```bash
cp sim/benchmark/.env.example sim/benchmark/.env
# Заполнить пути и параметры эксперимента.
make benchmarking-check
```

Команды вызываются из корня репозитория. Пути к входным данным (`CASES`,
`BENCHMARK_REPO_DIR`, `GENERATED_SKILLS_DIR`) в этом env-файле отсчитываются от
корня репозитория. Например, `generated-skills/<archive-directory>`.
Пути результатов `BENCH_RESULTS` отсчитываются от корня репозитория.
Пути, переданные аргументами Make, также отсчитываются от корня репозитория.

Настройки Docker-сервисов, снимок `DATA_DIR`, модель агента и API-ключи провайдера
остаются в `deploy/.env`. Клиентские URL и пароль доступа задаются отдельно здесь;
они должны соответствовать существующему стенду. Процессные переменные имеют
приоритет перед значениями, загружаемыми Python из env-файла.

Описание режимов, метрик и формата результатов:
[benchmark-execution-description.md](../../docs/benchmark-execution-description.md).
